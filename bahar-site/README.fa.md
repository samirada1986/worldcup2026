# سایت بهار افلاطونیان (فرانت‌اند)

این فرانت‌اند همهٔ محتوایش را از API بک‌اند (`../bahar-backend`) می‌گیرد. **هیچ محتوای نمونه‌ای داخل خود سایت نیست.**

## فایل‌ها

| فایل | کار |
|---|---|
| `index.html` | خود سایت: صفحه‌ها، طراحی، منطق |
| `support.js` | اجراگر کامپوننت‌های `.dc.html` (تغییرش ندهید) |
| `config.js` | **آدرس API** (فقط اینجا عوض کنید) |
| `vendor/` | React، روی همین هاست. سایت به unpkg.com وابسته نیست. |
| `fonts/` | فونت‌ها، روی همین هاست. سایت به Google Fonts وابسته نیست. |
| `favicon.svg`، `robots.txt` | آیکن سایت و قواعد موتورهای جستجو |

## دیپلوی

1. همهٔ فایل‌ها و پوشه‌های بالا را در `public_html/` (ریشهٔ سایت) آپلود کنید.
2. بک‌اند را در `public_html/backend/` نصب کنید (README بک‌اند).
3. `config.js` به‌طور پیش‌فرض این است:
   ```js
   window.BAHAR_API_BASE = '/backend/api/v1';
   ```
   اگر بک‌اند در همان دامنه و پوشهٔ `/backend` است، **هیچ تغییری لازم نیست**.
   - اگر سایت روی Netlify است و بک‌اند روی یک ساب‌دامین، آدرس کامل **https** را بگذارید (مثلاً `https://api.example.com/api/v1`) و دامنهٔ سایت را در `cors_origins` بک‌اند اضافه کنید.

## آدرس صفحه‌ها

هر صفحه آدرس مستقل دارد، پس دکمهٔ Back، Refresh و ارسال لینک کار می‌کنند:

| آدرس | صفحه |
|---|---|
| `#/works/shared-border` | مجموعهٔ مرز مشترک |
| `#/bio` | درباره |
| `#/writings` | نوشته‌ها |
| `#/contact` | تماس |

## اگر بک‌اند در دسترس نباشد

- سایت پیام «سایت بارگذاری نشد» را با دکمهٔ «تلاش دوباره» نشان می‌دهد. **هرگز محتوای ساختگی نشان نمی‌دهد.**
- فرم تماس فقط وقتی «پیام ارسال شد» می‌گوید که سرور واقعاً پیام را ذخیره کرده باشد.

## بخش‌های خالی

بخشی که در ادمین موردی برایش منتشر نشده (کتاب‌ها، پرینت‌ها، نوشته‌ها، رویدادها) از منو پنهان می‌شود.
