# 7. CMS guide — راهنمای مدیریت محتوا

نشانی: `https://<domain>/admin` · زبان رابط کاربری را از **Account → Language** روی فارسی بگذارید.
Address: `https://<domain>/admin` · Switch the admin UI language under **Account → Language**.

## فارسی

**زبان محتوا.** بالای هر صفحهٔ ویرایش منوی «Locale» هست. اول متن انگلیسی را وارد کنید، بعد Locale را روی «فارسی» بگذارید و ترجمه را بنویسید. فیلدهایی که کنارشان «— English» یا «— فارسی» نوشته شده دوزبانه‌اند. بقیه (مثل سال و ترتیب تصاویر) بین دو زبان مشترک‌اند.

**پروژهٔ جدید.**
۱. پروژه‌ها ← Create New.
۲. عنوان را بنویسید. پیش‌نویس خودکار ذخیره می‌شود.
۳. در زبانهٔ «توالی تصاویر» بلوک «توالی تصاویر» را اضافه کنید و چند عکس را یک‌جا بکشید و رها کنید. ترتیب را با کشیدن تغییر دهید.
۴. برای ترکیب‌بندی دقیق‌تر از بلوک‌های «تک‌تصویر»، «دوتایی»، «تمام‌عرض»، «تصویر با متن» و «فضای خالی» استفاده کنید.
۵. با دکمهٔ چشم (پیش‌نمایش) صفحه را ببینید.
۶. «Publish» را بزنید.
ترتیب پروژه‌ها در صفحهٔ آثار با کشیدن ردیف‌ها (☰) در فهرست پروژه‌ها تعیین می‌شود.

**تعویض عکس بدون شکستن صفحه‌ها.** کتابخانهٔ رسانه ← تصویر مورد نظر ← فایل جدید را جایگزین کنید (Replace). عنوان، متن جایگزین و زیرنویس حفظ می‌شوند و همهٔ صفحه‌هایی که از آن تصویر استفاده می‌کنند خودبه‌خود به‌روز می‌شوند. اگر تصویر «جایگزین موقت» بود، تیک آن را بردارید.

**نوشتهٔ جدید.**
۱. نوشته‌ها ← Create New.
۲. در ویرایشگر برای تصویر، نقل‌قول برجسته و پانویس از «+» یا «/» استفاده کنید. پانویس‌ها خودکار شماره‌گذاری می‌شوند.
۳. منابع را در بخش «منابع» وارد کنید.
۴. در «زبان‌های منتشرشده» زبان‌هایی را که متن‌شان کامل است تیک بزنید. نوشته‌ای که فقط به فارسی است در نسخهٔ انگلیسی سایت هم به فارسی و راست‌به‌چپ نشان داده می‌شود.

**زندگی‌نامه و رزومه.** هنرمند ← «پروفایل و رزومه هنرمند». نمایشگاه‌ها و انتشارات مجموعه‌های جداگانه‌اند و خودکار در رزومه می‌آیند. فایل PDF رزومه را هم همین‌جا بارگذاری کنید.

**صفحهٔ اصلی و تنظیمات** (فقط مدیر): تنظیمات ← «تنظیمات سایت». اثر شاخص، ترتیب آثار منتخب، منو، سئو و فرم تماس از این‌جا تنظیم می‌شوند.

**پیام‌ها:** هنرمند ← «پیام‌ها». نشانی ایمیل گیرنده هیچ‌وقت در سایت نمایش داده نمی‌شود.

## English

**Content language.** Use the **Locale** menu at the top of any edit screen. Fields labelled "— English" or "— فارسی" are translated. Other fields (year, image order) are shared between languages.

**New project.**
1. Projects → Create New. Type the title; the draft autosaves.
2. In the *Image sequence* tab, add an **Image sequence** block and drop several photos at once. Drag to reorder.
3. Use *Single image*, *Two-image spread*, *Full-width image*, *Image with text* and *White space* for an exact composition.
4. Click the eye icon to **preview**, then **Publish**.
5. Project order on the Works page: drag rows (☰) in the Projects list.

**Replace a photograph.** Media library → open the item → upload a new file. Its title, alt text and caption are kept, and every page that uses it updates. Untick "Placeholder" when the original is in.

**New essay.**
1. Writing → Create New. Insert images, pull quotes and footnotes with "+" or "/". Footnotes are numbered automatically.
2. Add references in *References*.
3. Tick each finished language under **Published languages**.

**Profile and CV.** Artist → *Artist profile & CV*. Exhibitions and Publications are separate lists and appear on the CV automatically. Upload the CV PDF there too.

**Homepage and settings** (administrators): Settings → *Site settings*.

**Messages** from the contact form: Artist → *Inquiries*.
