## What the benchmark changes in the design (inference, labelled as such)

1. **Series as a book, not a grid.** Photobook-led practitioners imply: sequence is authored; pairs are chosen; the viewer moves through plates in order. → the series page composes *plates* (large, pair, single) and keeps reading order sacred.
2. **Equal, quiet treatment.** Portrait-in-place practices imply no hierarchy of tricks: each photograph gets the same ground, caption format and respect. → one `Plate` component for every image.
3. **Text kept short; images first.** → the series page leads with one lede paragraph; long statements only if she writes them.
4. **Bilingual is part of the work for Iranian context.** → full RTL layout, Persian digits for plate numbers, Persian-first reading order of pairs.
5. **Archive/installation practices need a different layout.** → the `archive` mode (photograph beside a note) exists, unused today.
